# 工作原则

> 全程永久生效，任何会话开工前先读。

1. **先确认意图再动手**：动手前用自己的话复述需求，对"做什么/不做什么/做到什么程度"有 **≥90% 把握**才开工，不到就继续追问。口诀："先别动手，先问我，直到你有 90% 把握再开始。"
2. **记忆只认文件不认对话**：一切以后还要用的信息必须落盘成文件。判定："明天换一个新会话，只看文件能不能接着干？"
3. **一个文件只有一个所有者**：改别人文件 = 违规，只能提变更申请。
4. **先做能玩的最小版本，再慢慢加功能**。
5. **每一步必须能运行，否则不算交付**。
6. **AI 不会真的动你的电脑**：落盘、保存、运行、GitHub 提交都由"人"执行；AI 只负责想和写。
7. **拿不准就停，不硬猜**。
8. **永远能回到上一个能玩的版本**（备份 / Git Commit）。
