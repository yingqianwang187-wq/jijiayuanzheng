## B 变更单（scripts/data.gd / scripts/save.gd / scripts/game.gd）

【变更单】契约 v0.4 落地：挂机点收获 + 机娘经验系统（总指挥 A 派单）
背景：设计文档已升 v0.2，契约已升 v0.4。请按契约 v0.4 修改你的三个文件。
【必读】docs/契约.md（§1.2 / §1.3 / §3.2 / §3.5 / §3.6 / 变更记录 v0.4）、docs/设计文档.md v0.2（§8.4 数值）、scripts/contract.gd（只读，新增信号已声明）
【只允许修改】scripts/data.gd、scripts/save.gd、scripts/game.gd
【只读】scripts/contract.gd、docs/契约.md、docs/设计文档.md

1. data.gd：
   - 挂机金币基础 1 → 0.5（IDLE_GOLD_BASE），每过 1 关 ×1.25 不变；
   - 敌人数值按设计文档 v0.2 §8.4 表更新（攻 14/17/21/25/31、血 120/146/179/218/266，每关 1 敌）；
   - 新增升级经验曲线常量：UPGRADE_EXP_BASE := 15、UPGRADE_EXP_GROWTH := 1.25（所需经验 = roundi(15 × 1.25^(N-1))）；
   - LEVELS[level] 增加 victory_reward_exp = 10 + level × 3（13/16/19/22/25）；
   - 只放数据不放逻辑。
2. save.gd：
   - 存档形状改为 {gold, mechs{level, exp}, unlocked_level, first_cleared, idle_pending, idle_last_time}；
   - save_game() 写 mechs.exp、idle_pending、idle_last_time；load_game() 读回并钳制（exp ≥ 0、idle_pending ≥ 0、idle_last_time 非法取当前时间）；默认值：exp 0、idle_pending 0、idle_last_time 取当前时间戳（Time.get_unix_time_from_system()）。
3. game.gd：
   - 挂机改"点一下收获"：新增状态 idle_pending（float 累积额）、idle_last_time（时间戳）；启动时按"现在 - idle_last_time"把离线时长补入 idle_pending（离线收益）；每秒节拍把 rate × 1.0 累入 idle_pending 并发 idle_rewards_updated(roundi(idle_pending))；新增 collect_idle()：gold += int(idle_pending)，idle_pending = 0，idle_last_time = now，发 gold_changed + idle_rewards_updated(0)，并 Save.save_game()；待收获每 5 秒节流存档（沿用 Data.SAVE_THROTTLE_INTERVAL）；
   - 机娘经验：新增 mech_exp（{id: int}）；胜利时全体上阵机娘 + victory_reward_exp，发 mech_exp_updated(id, exp, exp_next)（exp_next = 当前等级升下一级所需经验）；失败不发经验；
   - upgrade(mech_id)：校验金币 ≥ 金币费用 且 经验 ≥ 所需经验；两者都够才扣（经验扣减、余额保留），等级 +1，发 gold_changed / mech_girl_updated / mech_exp_updated，Save.save_game()；
   - get_save_snapshot() 返回形状同步 v0.4（含 mechs.exp、idle_pending、idle_last_time）；
   - 删除旧注释中"挂机金币每秒自动入账"的表述。
【验收】
① 挂机攒"待收获"，点收获一次性入账（关游戏再开，离线时长也补入）；
② 升级需金币 + 经验，经验不足无法升级；
③ 胜利给经验、失败不给；非首通重复胜利也给；
④ 刷新页面后待收获金额、机娘经验都在。
【汇报】末尾输出【交付说明】。

【变更单】契约 v0.6：挂机同产经验 + 经验分两路 + 右上角余额数据（总指挥 A 派单）
【必读】docs/设计文档.md v0.3（§3.2 / §3.3 / §3.7 / §8.4）、docs/契约.md（§1.2 / §3.2 / §3.5 / §3.6 / §3.7 / 变更记录 v0.6）、scripts/contract.gd（只读，v0.6 已声明新信号）

1. data.gd：新增挂机经验比例常量 `IDLE_EXP_RATIO := 0.5`（挂机经验 = 待收获金币 × 0.5，设计文档 §8.4"1 金币 = 0.5 经验"）；只放数据不放逻辑。
2. save.gd：存档形状改为 `{gold, exp_balance, idle_pending, idle_pending_exp, idle_last_time, unlocked_level, first_cleared, mechs{level, exp}}`；写/读并钳制（exp_balance ≥ 0、idle_pending ≥ 0、idle_pending_exp ≥ 0、idle_last_time 非法取当前时间）；默认值：exp_balance 0、idle_pending 0、idle_pending_exp 0。
3. game.gd：
   - 新增状态：`idle_pending_exp`（float）、`exp_balance`（int）。
   - 挂机节拍：idle_pending += rate、idle_pending_exp += rate × Data.IDLE_EXP_RATIO；发 `idle_rewards_updated(roundi(idle_pending), roundi(idle_pending_exp))`；离线时长同样按 rate 与 rate×IDLE_EXP_RATIO 补入二者；待收获金币/经验每 5 秒节流存档。
   - `collect_idle()`：gold += roundi(idle_pending)；exp_balance += roundi(idle_pending_exp)；清零二者；发 gold_changed、exp_balance_updated(exp_balance)、idle_rewards_updated(0,0)；存档。

   - 战斗胜利经验：仍进**个人经验条**（mech_exp[id] += victory_reward_exp，发 mech_exp_updated），不进余额——保持不变。
   - 启动读档后发初始信号：gold_changed、mech_girl_updated、mech_exp_updated、exp_balance_updated、level_progress_changed、idle_rewards_updated(roundi(idle_pending), roundi(idle_pending_exp))。
   - `get_save_snapshot()`：返回形状同步 v0.6（含 exp_balance、idle_pending_exp、mechs.exp）。
【验收】① 挂机同时累计待收获金币与经验；点收获金币入账、经验入全局余额，右上角两个余额都更新；② 战斗胜利经验进机娘个人条（不进余额）；非首通重复胜利也给；③ 升级先扣个人条、不足自动从余额补；个人条+余额都不足则不能升级（无反应/提示）。
