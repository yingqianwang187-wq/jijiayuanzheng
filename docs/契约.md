## ① 世界观与玩法

### 1.1 世界观（设计文档 §1，已确认）
- 近未来都市，人类城市被失控的机械军团（暴走 AI）攻陷。
- 玩家身份：**指挥官**，率领机甲少女（机娘）小队**自动推关**，夺回被机械军团占领的家园。
- 基调：轻松搞笑；每章开头 2~3 句小对话（阶段 3 实装），MVP 不做剧情。

### 1.2 玩法（MVP = 阶段 0，设计文档 §9 + 手册 §2.3）
- **机娘**：MVP 初始小钰（近战·R）、阿岚（远程·R）；**阶段 1 起经抽卡可获新机娘**（卡池 30 位，见 §3.8 / Data）；成长 = **等级 + 升星** 两线——升星 1~10 星（**1~5 星碎片升星**，每星基础属性 +8%；**6~10 星需满级 100 解锁**，每星 +20 级上限：5★100 级 → 10★200 级；碎片消耗按稀有度 R30/SR60/SSR100 片/星）。
- **关卡**：第 1 章 5 关，每关 1 波敌人，自动战斗，**每秒结算一轮**。
- **挂机（点一下收获，同产金币+经验）**：金币、经验都不自动进账；按"距上次收获 / 上次打开的实际经过时长 × 每秒产出"累计**待收获金币**与**待收获经验**（**1 金币 = 0.5 经验**；在线+离线均计入），点击一次性领取——金币入账，经验入**全局经验余额**。
- **经济循环**：挂机收获 / 推关 → 金币入账 + 经验入**全局经验池**（挂机随收获、战斗胜利直接进池，全体机娘共享；v0.22 取消个人经验条）→ **手动点升级**（金币 + 经验同时从池扣，池不足提示"经验不足"不能升级）→ 推更远 → 首通钻石（阶段 1 起用）→ 抽卡 → 更强机娘 → 再推关。
- **存档**：本地存档（金币、全局经验余额、待收获金币/经验、机娘等级与个人经验、解锁关卡、首通记录）；**自动存档**（升级/通关即时、待收获金额与时间戳节流保存）；换设备/清浏览器会丢（MVP 接受）。
- **开局资源（v0.18）**：**仅新档**金币 1000 + 钻石 300、机娘初始 1 级（旧档保留原值，走字段补齐不覆盖）。
- **画面**：先用简单图形/头像代替立绘（后续换正式立绘）。
- **抽卡（阶段 1）**：用钻石在**常驻池 / 新手池**抽卡获得机娘或碎片；含保底与新手福利；详见 §3.8。抽到的新机娘加入我方（上阵 = 拥有的机娘，≤5，按 Data 顺序；开局 2 位仍 2v1）。
- **验收标准**（来自设计文档）：打开网页 → 看到机娘自动打关 → 挂机收获金币+经验（右上角余额正确）→ 打关得经验进个人条 → 升级机娘（金币+经验，个人条不足自动用余额补）→ 打过 5 关 → 刷新页面进度还在。

### 1.3 战斗规则（设计文档 §8.3 + 手册 §2.2，已确认）
- **每秒结算一轮**（节拍结算）：按速度排序先后出手 → 我方全体攻击一次 → 敌方全体攻击一次 → 结算血量 → 发信号。
- 胜负结果：**敌人全灭 = 胜利** → 首通发放金币奖励 + 钻石 + **小钰碎片**（普通关 1 片 / 章节 BOSS 关 3 片）并解锁下一关，且发放该关经验入**全局经验池**（v0.22：不再分发给个人条）；**我方全灭 = 失败** → 无经验、可重试当前关。
- **主线推进规则（v0.15）**：主线**不允许选关**——只能挑战**当前最高未通关的下一关**（Game 校验）；**不允许扫荡**（扫荡仅保留给秘境，阶段 3 实装）；首通奖励一次性、**不可重打旧关**（原"非首通重复胜利给经验"对主线不再适用）；练级途径 = 秘境经验副本 + 挂机经验 + 经验药水。
- **返回主界面 = 中止本局战斗**（`Game.stop_battle()`，可重进重打；战斗不会在后台继续）。
- 血量归零即退场；**阶段 0/1：2 名机娘 vs 每关 1 名敌人**；**阶段 2（战斗 2.0）起：我方 5 名 vs 敌方每波最多 5 名**，双方各 3x3 九宫格战场（§3.9）。
- 节拍间隔、伤害公式等具体数值属 Data（§3.3），契约只约定"怎么通知"，不约定"怎么算"。

### 1.4 货币（设计文档 §3，已确认）
| 货币 | 代码术语 | 获取 | 用途 | MVP 是否涉及 |
|---|---|---|---|---|
| 金币 | gold | 挂机产出、关卡首通 | 机娘升级等基础消耗 | ✅ 唯一涉及 |
| 钻石 | diamond | 首通、每日/周活跃度奖励 | 抽卡、加速挂机、买金币 | ✅ 阶段 1 起 |

## ③ 接口约定（重点）

### 3.1 数值唯一变更方 = Game
- 金币、机娘状态、敌人状态、关卡进度等一切**会变的数值**，只允许 Game 修改。
- Game 每次修改后，必须通过 Contract 上声明的信号通知（emit）。
- UI（main_ui / battle_view）**只 connect 信号来显示**，绝不自己改数值、绝不 emit 信号。
- 红线（代码评审必查）：
  - UI 脚本中不允许出现 `gold =`、`hp =` 之类的赋值；
  - UI 脚本中不允许出现 `emit_signal` / `.emit(`；
  - 一切显示值以信号参数为准，UI 不缓存、不推算。
- **首屏铺底例外**（v0.3 明确）：进入战斗 / 返回主界面等场景切换时，切换前发出的信号 UI 收不到，故允许 UI 在 `_ready()` 时对 Game 公开状态做**一次只读快照**用于首次显示；此后一切更新一律走信号。快照只读——仍禁止写数值、禁止 emit、禁止缓存后续值。

### 3.2 存档唯一负责方 = Save
- 只有 Save 知道存档文件路径与格式（`user://save.json`，FileAccess + JSON）；其他脚本不得直接读写存档文件。
- 公开接口：
  - `save_game()`：**无参数**，把当前状态写入存档；当前状态唯一持有者是 Game（§3.1），Save 经 `Game.get_save_snapshot()` 取**只读快照**后写档；
  - `load_game() -> Dictionary`：读档，**失败（缺失/损坏/版本不符）必须返回默认值并继续运行，不允许报错崩溃**；读档/默认值逻辑**不依赖 Game**。
- **自动存档时机**（由 Game 调用，契约约定）：
  - 升级成功、通关（level_cleared）后：**即时**调用 `Save.save_game()`；
  - 挂机待收获：**每 5 秒节流**存一次（待收获金额 + 时间戳；节流间隔属数值，由 B 放入 Data）。

### 3.4 战斗 = 节拍结算
- 战斗节奏由 Game 掌控：每秒 1 轮，按速度排序结算我方一次攻击、敌方一次攻击，更新血量后发信号。
- battle_view 只做三件事：**连接信号 → 刷新血条 → 播放表现**；不做物理碰撞、不做位移运算、不自己扣血。
- 血条数值唯一来源：Game 发出的信号参数。

### 3.7 右上角余额展示（设计文档 §3.7，已确认）
- 页面**右上角**常驻展示两项：**金币余额**、**经验余额**（均含待收获部分）。
- 金币余额 = 已入账金币 + 待收获金币；经验余额 = 全局经验余额 + 待收获经验。
- 展示形式：如 `金币 1,234 (+567)` / `经验 890 (+280)`，"+"为待收获部分，点击"收获"后并入。
- 数据来源（只读）：金币（gold_changed + 快照 Game.gold）、待收获金币（idle_rewards_updated 的 gold + 快照 Game.idle_pending）、全局经验余额（exp_balance_updated + 快照 Game.exp_balance）、待收获经验（idle_rewards_updated 的 exp + 快照 Game.idle_pending_exp）。

### 3.9 战斗系统 2.0（阶段 2；设计文档 §2.5 / §8.3 / §10.10，v0.14 定稿）
- **战场**：我方/敌方各 **3x3 九宫格**；我方上阵最多 5 名、9 格任意选 5 格布阵；敌方每波最多 5 名、AI 自动排阵（前排肉后排输出）。位置只影响接敌顺序、无属性加成。
- **战斗全自动**：自动普攻、自动放小技能/大招；玩家只管布阵 + 养成。**目标选择**：优先正前/同列最近敌人；前排全灭打后排。
- **职业**：6 大职业（坦克/战士/刺客/射手/法师/辅助）；**职业克制环**（坦克→刺客→射手→法师→战士→坦克，辅助中立）：克制 +20%、被克 -10%。
- **技能**：每名机娘 **1 被动 + 2 小技能（CD 3~5 轮，到轮自动放）+ 1 大招（能量制）**；敌人同理（普通 1 技、BOSS 2 小技 + 1 大招，共用技能模板库）。技能数据放 Data（设计文档 §2.5.1/§2.5.2）。
- **能量**：普攻命中 +10、受击 +10；能量 100 满格自动放大招（放完清零）；满后普攻不再加、被闪避不加。
- **伤害公式**：伤害 = 攻击 × 技能倍率 − 防御；**减伤下限 30%**；暴击 = 该值 × 150%。暴击率基础 10%、闪避率 5%（闪避则该次伤害 0）。
- **状态效果**：眩晕（跳过行动）/灼烧/中毒（每轮掉血）/加攻/减防/治疗/护盾；持续 3 轮、同效果不叠加只刷新时长。
- **波次/BOSS**：每关可设 1~3 波；每章最后 1 关为 BOSS 关（高血高攻、带大招）。**60 轮超时**按双方剩余血量百分比判定胜负。
- **评价与奖励**：每关 **1~3 星**（无人阵亡=3 星），星级/单关星奖/章节星数宝箱见设计文档 §1.3；**2x 加速**保留；**扫荡仅限秘境**（阶段 3 实装，主线不开放）。
- **战后统计**：简版伤害/治疗统计；**战斗提示按事件分色**（命中/暴击/闪避/击杀/技能/治疗/护盾）。
- **阵型**：布阵入档保存；可存 2~3 套预设一键切换。
- **战斗判定细则（v0.18）**：① 先判定闪避、后判定暴击（被闪避不判暴击）；② 护盾**可叠加、优先吸收、不吃减伤**；③ **嘲讽只影响普攻 + 单体技**（AOE 不受影响）；④ 被控单位**不加能量（含受击：被控期间受击也不加能量）、不叠新控**；⑤ 追击/连击/反击**算普攻**（可触发被动、可暴击/闪避、可获能量；追击不可再触发追击）；⑥ 多波战斗：**我方状态延续、敌波刷新**；⑦ 失败**无惩罚可重试**、不做复活、治疗溢出浪费；⑧ 普攻目标兜底：**同列 → 最近 → 任意**。
- **数据归属**：30 位机娘（含职业/技能）、敌人技能模板库、章节结构（波次/BOSS）、克制环、状态表、倍率/CD/概率、升星数值（碎片消耗/属性加成/等级上限）等全部放 Data；契约只约定信号/入口/术语。
