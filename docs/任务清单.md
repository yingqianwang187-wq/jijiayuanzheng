# 任务清单 · 机娘放置挂机游戏（机甲远征）MVP

- 版本：v0.2（配套契约 v0.2）
- 作者：总指挥 A（拆任务、派单用）
- 依据：`机甲远征·完整开发手册.md` 第六节、`docs/契约.md`
- 铁律：每个任务**只允许创建/修改"输出文件"这一个**；其余输入文件一律**只读**（工作原则第 3 条）。依赖顺序：1 → 2 → 3（B 组），4 → 5、6 → 7（C 组可并行），8 最后（A 装配）。

---

## 任务 1：数值表
- 负责角色：B
- 输入文件：docs/设计文档.md（§8 数值）、docs/契约.md（§3.3、术语表）、scripts/contract.gd（只读）
- 输出文件：scripts/data.gd
- 验收标准：
  1. 含 2 位机娘（小钰·近战·R、阿岚·远程·R）与 5 关配置，每关 1 波敌人；
  2. 机娘字段含：名 / 攻击(atk) / 血量(hp) / 防御(def) / 速度(spd) / 升级费用曲线 / 升级成长；关卡字段含：敌人列表 / 奖励金币（含首通奖励）；
  3. 只放数据不放逻辑：无函数实现、无信号 emit、无运行时代码（纯常量 / 字典表）。

## 任务 2：存档
- 负责角色：B
- 输入文件：docs/契约.md（§3.2）、scripts/data.gd、scripts/contract.gd（只读）
- 输出文件：scripts/save.gd
- 验收标准：
  1. 提供 `save_game()`（**无参数**，经 `Game.get_save_snapshot()` 取只读快照）/ `load_game()`，load 返回 `{gold, mechs, unlocked_level, first_cleared}` 形状；
  2. 读失败（文件缺失 / 损坏 / 版本不符）**返回默认值、不报错崩溃**，默认值含 Data 中的初始机娘配置、`first_cleared` 为空；
  3. 用 FileAccess 读写 `user://save.json`，JSON 格式；**读档/默认值逻辑不依赖 Game**。

## 任务 3：战斗 + 挂机 + 养成（核心）
- 负责角色：B
- 输入文件：docs/契约.md（§3.1 / §3.4 / §3.5 / §3.6）、scripts/data.gd、scripts/save.gd、scripts/contract.gd（只读）
- 输出文件：scripts/game.gd
- 验收标准：
  1. 自动战斗：每秒 1 轮节拍结算，按速度排序双方先后出手；敌人全灭 → 发 `level_cleared` 并解锁下一关；我方全灭 → 发 `battle_failed`（失败可重试）；
  2. 挂机：每秒自动加金币并发 `gold_changed`；养成：`upgrade(mech_id)` 扣金币 → 升等级 → 提攻血并发信号；**自动存档**：升级/通关即时、挂机金币每 5 秒节流调 `Save.save_game()`；
  3. 是**唯一改数值者、唯一 emit 信号者**：所有状态变化都经 Contract 信号通知（契约 §3.1 / §3.5）。

## 任务 4：战斗画面脚本
- 负责角色：C
- 输入文件：docs/契约.md（§3.4 / §3.5）、scripts/contract.gd（只读）
- 输出文件：scripts/battle_view.gd
- 验收标准：
  1. 只 connect 信号（`battle_tick` / `mech_girl_updated` / `enemy_updated` / `battle_failed`）刷新血条与状态显示（含失败/重试提示）；
  2. 脚本内**无任何数值赋值**（如 `hp =`）、无 `emit`、无物理碰撞 / 位移逻辑；
  3. 刷新目标按信号参数定位，血条节点命名符合术语 `hp_bar`。

## 任务 5：战斗场景
- 负责角色：C
- 输入文件：scripts/battle_view.gd、docs/契约.md（术语表、组名）
- 输出文件：scenes/Battle.tscn
- 验收标准：
  1. 根节点挂 battle_view.gd；
  2. 含双方机娘节点（组 `mech_girl` / `enemy`）与血条节点（命名 `hp_bar`）；
  3. 编辑器可正常打开，无缺失资源报错。

## 任务 6：主界面脚本
- 负责角色：C
- 输入文件：docs/契约.md（§3.5 / §3.6）、scripts/contract.gd（只读）
- 输出文件：scripts/main_ui.gd
- 验收标准：
  1. connect `gold_changed` / `level_progress_changed` / `level_cleared` 显示金币与关卡进度；
  2. 升级 / 进入战斗 / 存档按钮**只调用** `Game.upgrade` / `Game.start_battle` / `Save.save_game`（契约 §3.6），绝不自己改数值；
  3. 无 `emit`、无数值赋值。

## 任务 7：主界面场景
- 负责角色：C
- 输入文件：scripts/main_ui.gd、docs/契约.md
- 输出文件：scenes/Main.tscn
- 验收标准：
  1. 根节点挂 main_ui.gd；
  2. 含金币显示、机娘列表、升级按钮、关卡选择、**"进入战斗"按钮**（跳转 res://scenes/Battle.tscn）；
  3. 编辑器可正常打开，无缺失资源报错。

- 输出文件：project.godot
- 验收标准：
  1. 注册 4 个自动加载，顺序 Contract → Data → Save → Game；
  2. `run/main_scene = res://scenes/Main.tscn`；
  3. F5 全流程可跑：进主界面 → 进战斗 → 挂机涨金币 → 升级 → 打过 5 关 → 刷新页面进度还在（无脚本报错）。
